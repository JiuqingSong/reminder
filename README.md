# 不着急 · Will Do

说一句就记下，到店告诉你买什么。

一个简单安静的 iPhone 提醒 App：提醒按事件逐条列出，不按日历组织，一眼就能看到接下来要做什么。在 App Store 搜索"不着急"或"Will Do"即可下载。

## 提醒

- 可以设日期、日期加时间，或者不设日期，作为常年记着的事固定在列表顶部
- 提前几天开始提醒，每天在你选的时刻汇总发一条通知
- 过期的事每天继续提醒，直到完成
- 支持每天、每周、每月、每年重复，可自定义间隔
- 左划完成；长按可以推迟一天或一周

## 待买清单

- 物品可以带文字、图片和链接，也可以一次粘贴整张清单
- 为每件物品选购买地点：在地图上搜索商店，可以加多家分店
- 开启到店提醒后，到达有东西要买的商店时会收到通知
- 循环购买的物品在"需要买"和"以后检查"之间切换，不会消失

## 其他

- 拍照或从相册添加图片
- 链接、电话号码、地址可以直接点开，地址用 Google 地图打开
- 通知自动显示在 Apple Watch 上
- 用 Siri 说一句话添加提醒，自动识别日期和时间（目前支持中文普通话）
- 简体中文、繁体中文、英文
- 可导出备份到"文件"或 iCloud Drive，随时恢复

## 隐私

所有数据只存在你的 iPhone 上，没有账号，没有服务器，不收集任何数据。详见[隐私政策](https://jiuqingsong.github.io/reminder/privacy.html)。
